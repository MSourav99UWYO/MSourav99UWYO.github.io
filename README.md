# sourav-majumder.com

Personal site. Static HTML + Tailwind CSS + vanilla JS.

## Stack

- HTML + Tailwind CSS (compiled, not CDN) + vanilla JS
- Markdown → HTML blog with a 90-line Node build script
- KaTeX for math, BibTeX-copy buttons for publications, RSS for the blog, dark mode
- No framework, no bundler, no client-side router

## Local setup

```bash
npm install
npm run build      # compiles CSS + builds blog
npm run dev        # rebuilds + serves on :8080
```

Or watch CSS only while editing:
```bash
npm run watch:css
```

## Updating content

### Add a publication

Edit `assets/data/publications.json`. Each entry needs `title`, `authors`, `venue`, `year`, and a `bibtex` block. Optional: `doi_url`, `pdf_url`, `abstract`, `tags`.

### Add a blog post

1. Create `blog/posts/YYYY-MM-DD-my-slug.md`
2. Add YAML frontmatter:
   ```yaml
   ---
   title: My post title
   date: 2026-05-22
   excerpt: One-line summary for index + RSS.
   tags: [research, ethereum]
   ---
   ```
3. Write Markdown. `$inline$` and `$$display$$` math is rendered by KaTeX client-side.
4. Run `npm run build:blog`. This regenerates the post HTML, `posts.json`, and `rss.xml`.

### Update CV PDF

Drop the new file at `assets/pdf/sourav-majumder-cv.pdf`. The CV page links to it directly.

### Add your profile photo

Put `profile.jpg` (square, 600×600 or larger) at `assets/img/profile.jpg`. Until then, the home page falls back to an "SM" monogram automatically.

### Change the accent color or fonts

Both live in `tailwind.config.js` → `theme.extend.colors` and `fontFamily`. After editing, run `npm run build:css`.

## Deploy

Pick one. All are free and support custom domains.

**GitHub Pages.** Push to GitHub, enable Pages in repo settings, point at the `main` branch root. Add a `CNAME` file with your domain.

**Netlify.** Drag the project folder into the Netlify dashboard, or connect the repo and set build command `npm run build`, publish directory `.`.

**Cloudflare Pages.** Same as Netlify; build command `npm run build`, output `.`.

Before deploying, set `SITE_URL` in `scripts/build-blog.js` (or pass as env var) so RSS links point to the right domain:

```bash
SITE_URL=https://your-domain.com npm run build:blog
```

## Notes

- Tailwind config uses `content` paths that exclude `node_modules`. Don't add `./**/*.html`.
- Dark mode is `class`-based, persisted to `localStorage`, with an inline `<script>` in `<head>` to prevent flash on load.
- BibTeX copy uses `navigator.clipboard` — requires HTTPS in production.
- KaTeX is loaded from jsDelivr (about 150KB). If you don't blog with math, you can remove the KaTeX `<link>` and `<script>` tags from `scripts/post-template.html` and rebuild.
- The `home-pubs.js`, `home-posts.js`, `blog-index.js`, and `publications.js` loaders all `fetch` JSON, so the site must be served over HTTP (not opened as `file://`). Use `npm run dev`.
